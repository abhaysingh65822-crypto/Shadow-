# Setup & Configuration Guide

## Requirements
- Android SDK 36 (target), 24 (minSdk)
- Gradle with Kotlin 2.2 / Compose plugin
- Java 11 / 17 toolchain

## Configuration Options
1. **Google Gemini API**:
   - In AI Studio, configure `GEMINI_API_KEY` in the Secrets panel, or paste in Settings screen.
2. **OpenAI API**:
   - Paste OpenAI API key starting with `sk-...` in the Settings screen.
3. **Offline / Prototype Mode**:
   - No configuration required! StudyForge runs fully offline with its local STEM knowledge engine and pre-loaded seed data.
